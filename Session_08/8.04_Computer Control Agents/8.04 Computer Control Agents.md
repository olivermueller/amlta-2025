# Computer Control Agents

Computer Control Agents, also called GUI agents, are AI systems based on large language models that can directly interact with graphical user interfaces such as operating systems, software applications, and web browsers. Unlike traditional chatbots that only produce text, these agents can observe screens, interpret interface elements, and perform actions like clicking buttons, typing text, navigating menus, and completing multi-step tasks autonomously based on high-level user instructions ([Hu et al., 2025](https://doi.org/10.18653/v1/2025.acl-long.369); [Nguyen et al., 2025](https://doi.org/10.18653/v1/2025.findings-acl.1158); [Sager et al., 2025](https://doi.org/10.48550/ARXIV.2501.16150)).

They are relevant because they represent a major step from conversational AI toward actionable AI. By operating in the same digital environments as humans, Computer Control Agents can bridge the gap between reasoning and execution. This makes them powerful tools for productivity and large-scale automation, but also exposes them to challenges such as cognitive biases inherited from LLMs and manipulation techniques embedded in human-centered interfaces, including digital nudges ([Marreed et al., 2025](https://doi.org/10.48550/ARXIV.2503.01861); [Haki et al., 2023](https://doi.org/10.1007/s12525-023-00609-8)).

Typical use cases include automated information retrieval, form filling, data extraction, online shopping, and software configuration. In organizational settings, these agents can automate repetitive workflows across multiple applications, while for individuals they enable task delegation, where users specify goals and the agent carries out the necessary steps independently. As a result, Computer Control Agents support both automation and delegation of digital work, reducing manual effort and enabling users to focus on higher-level decision-making ([OpenAI, 2025c](https://openai.com/index/introducing-chatgpt-agent/); [Singla et al., 2025](https://www.mckinsey.com/~/media/mckinsey/business%20functions/quantumblack/our%20insights/the%20state%20of%20ai/november%202025/the-state-of-ai-in-2025-agents-innovation-and-transformation.pdf?shouldIndex=false)).
